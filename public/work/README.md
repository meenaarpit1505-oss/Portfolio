# Project Case Study Assets (`public/work/`)

This directory contains the visual exhibits and gallery media for all featured projects showcased across the portfolio.

## Asset Notice: Current Files Are Placeholders

The current `.webp` files in each project subfolder are procedural placeholders designed to test layout geometry, responsive dimensions, and loading pipelines.

## Replacing With Real Project Imagery

When preparing your real project imagery, replace the files in each project folder (`public/work/<slug>/`) adhering to the following specifications:

- **Hero Visual (`hero.webp`):**
  - Dimensions: `1920 x 1080` px (16:9 aspect ratio)
  - Format: WebP
  - File size: under `400 KB`
- **Gallery Visuals (`gallery-1.webp`, `gallery-2.webp`, `gallery-3.webp`):**
  - Exactly 3 gallery images per project
  - Dimensions: `1200 x 800` px (or 16:9 / 3:2)
  - Format: WebP
  - File size: under `400 KB` each
